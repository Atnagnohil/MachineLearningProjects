### ⚙️ 1. 决策树：基于排序和阈值分割，不依赖距离
**核心机制：**  
决策树通过在单个特征上寻找最优的**分割点（阈值）** 来递归地划分数据空间。  

**寻找分割点的依据：**  
- **基于概率的不纯度（目标函数）：** 信息增益、信息增益率、基尼不纯度等。这些指标的计算**只依赖于特征值在分割点两侧的类别分布（概率）**。  
- **基于排序：** 算法需要将数值特征的所有值**排序**，尝试相邻值的中点作为候选分割点。关键依赖特征是**相对排序关系**和分割点两侧的类别**计数**。  

**为什么归一化影响小？**  
- **排序不变性：** 线性变换（如`x_new = (x - min)/(max-min)`）**不改变特征值的相对顺序**（例如 `[5, 10, 15]` → `[0, 0.5, 1]`，但 `5<10<15` 的关系不变）。  
- **不依赖绝对距离：** 目标函数（如基尼指数）基于分割点左右**数据点数量和类别比例**，线性变换后这些值不变。  
- **特征独立性：** 每次分割只关注**单一特征**，不计算特征间的组合距离（如欧氏距离）。特征尺度差异（如特征A范围0-1 vs. 特征B范围0-10000）不影响分割结果。  

---

### 📐 2. 逻辑回归和SVM：基于距离和权重，依赖尺度
**核心机制：**  
- **LR：** 通过线性函数 `z = w₁x₁ + w₂x₂ + ... + b` 定义决策边界，优化**权重向量**最小化对数似然损失。  
- **SVM：** 通过线性函数 `w·x + b = 0` 定义最大间隔超平面，优化**权重向量**最大化间隔（或最小化损失）。  

**关键依赖：距离和梯度**  
- **距离计算：**  
  - LR：点距决策边界 `z=0` 依赖加权和 `z`。  
  - SVM：间隔大小由 `||w||` 控制，点距超平面为 `|w·x + b| / ||w||`。  
- **梯度下降：** 权重更新量正比于**特征值大小**（`∂Loss/∂wᵢ ∝ xᵢ * 误差`）。  

**为什么归一化至关重要？**  
- **权重尺度失衡：**  
  - 例：特征A（范围0-1）需权重 `w₁≈1`，特征B（范围0-10000）需权重 `w₂≈0.0001`。  
- **梯度幅度失衡：**  
  - 大尺度特征（如特征B）梯度 `∂Loss/∂w₂` 极大，小尺度特征梯度极小，导致：  
    1. **收敛困难**：优化过程不稳定，需精细调整学习率。  
    2. **决策边界被大尺度特征主导**：模型过度关注大尺度特征，忽略重要的小尺度特征。  
- **正则化扭曲：** 正则化项（如L2）平等惩罚所有权重，导致对小尺度特征**过度惩罚**，降低模型效果。  
- **SVM对距离的严格依赖**：间隔计算依赖 `||w||`，特征尺度差异使间隔失效。

### 📌 总结
| 特性               | 决策树                   | 逻辑回归/SVM                     |
| ------------------ | ------------------------ | -------------------------------- |
| **决策核心**       | 基于排序和阈值分割       | 基于特征线性组合的加权和         |
| **依赖绝对距离**   | 否（只看排序和计数）     | 是（距离、加权和、梯度）         |
| **归一化影响**     | 很小（排序不变）         | 非常大（影响权重平衡和梯度收敛） |
| **特征独立性**     | 强（分割只关注单一特征） | 弱（特征通过权重线性组合）       |
| **受尺度差异影响** | 很小                     | 很大（需特征缩放）               |

**简单比喻：**  
- **决策树：** 像独立提问：*“温度 > 25°C吗？”*。温度单位（℃/℉）或收入数值范围不影响阈值判断，只需保留**相对大小**。  
- **逻辑回归/SVM：** 像计算加权总分 `总分 = (温度 × w₁) + (收入 × w₂)`。**必须统一单位**（如将收入从“元”缩放为“万元”），否则 `w₂` 被大数值带偏。  
  → **归一化**将特征置于相同价值天平。  

**实践建议：**  
- **决策树类模型**（随机森林、XGBoost）：通常可**跳过归一化**。  
- **线性模型**（LR、线性SVM）和**基于距离的模型**（KNN、RBF核SVM）：**必须归一化**（如Z-score或[0,1]缩放）。
