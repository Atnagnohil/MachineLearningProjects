## 🎯 问题本质：**权重分布到底如何影响弱模型训练？**

答案：**权重直接影响弱学习器的训练目标函数、损失函数或者数据采样方式。**

### 💡 不同弱学习器的处理方式会不同，下面是最常见两类：

------

## ① 分类桩（decision stump）或决策树类模型（如 CART）

### ✅ 做法：**加权计算损失（如加权 Gini 或加权错误率）**

> 在划分节点、选择最优特征或阈值时，不再使用样本个数，而是用“样本权重和”来计算“分类错误率”或“信息增益”。

### 📌 例子：

假设你有 5 个样本：

| 样本 | 标签 | 权重 |
| ---- | ---- | ---- |
| x1   | +1   | 0.1  |
| x2   | +1   | 0.1  |
| x3   | -1   | 0.6  |
| x4   | +1   | 0.1  |
| x5   | -1   | 0.1  |

- 你在训练这个 stump（单层决策树）时，会选择划分方式，使得**总权重误差最小**。
- 错误率 = 被分错样本的“权重和”

例如：

- 假设某个划分导致 x3 和 x5 被分错 → 错误率 = 0.6 + 0.1 = 0.7
- 换个划分，x1、x2 被分错 → 错误率 = 0.1 + 0.1 = 0.2 ✅ 更优

👉 **弱分类器直接按权重“加权学习”了！**

------

## ② 非树类模型（如线性模型）

### ✅ 做法：**带权损失函数**

比如你用逻辑回归、SVM 之类做弱分类器，损失函数会长这样：

Loss=∑i=1nwi⋅ℓ(f(xi),yi)\text{Loss} = \sum_{i=1}^n w_i \cdot \ell(f(x_i), y_i)

其中：

- wiw_i：样本权重
- ℓ\ell：单样本损失（如 hinge loss、cross-entropy）

👉 损失函数的每一项都被样本权重调节了，“错误且权重大”的样本对优化更敏感。

------

## ③ 有时也用 **加权重采样（weighted sampling）**

部分实现中（比如 Scikit-learn 中的 `SAMME.R` 模式）会用：

> **按权重重新采样一组训练数据集**

这就等价于训练数据中“错的样本重复出现得多”，从而模型自然更容易专注它。

------

## 🔁 迭代之后权重怎么变？

给你公式感受下（以分类误差为例）：

1. 弱分类器误差率：

εm=∑i=1nwi⋅1[hm(xi)≠yi]∑wi\varepsilon_m = \frac{\sum_{i=1}^n w_i \cdot \mathbf{1}[h_m(x_i) \ne y_i]}{\sum w_i}

1. 分类器权重：

αm=12ln⁡(1−εmεm)\alpha_m = \frac{1}{2} \ln \left( \frac{1 - \varepsilon_m}{\varepsilon_m} \right)

1. 样本权重更新（简化版本）：

wi(m+1)=wi(m)⋅exp⁡(−αmyihm(xi))w_i^{(m+1)} = w_i^{(m)} \cdot \exp\left(-\alpha_m y_i h_m(x_i)\right)

------

## ✅ 总结一句话

> **权重在具体实现中被用于计算加权损失或加权误差，从而影响模型的训练目标函数，使模型更关注被错分的样本。**
