# 决策树详解：分类树 vs 回归树

## 🧠 核心思想（两者共有）
- **递归二分法**：从根节点开始，递归地将数据集划分为更小的子集
- **贪婪搜索策略**：每次分裂时只考虑当前最优分裂，不考虑长期影响
- **树形结构**：由根节点、内部节点（决策点）和叶子节点（预测结果）组成
- **停止条件**：当满足以下任一条件时停止分裂：
  - 节点样本数<阈值
  - 树深度达到最大值
  - 纯度提升<阈值
  - 无更多特征可用

## 📊 分类树（用于离散目标变量）

### 🔎 关键概念
- **目标变量**：离散类别（如"是/否"，"猫/狗/鸟"）
- **节点纯度衡量**：
  - **基尼不纯度**：$Gini(t) = 1 - \sum_{k=1}^K p_k^2$
    - $p_k$=节点t中类k的比例
    - 值域[0,1]，0表示完全纯净
  - **信息熵**：$Entropy(t) = -\sum_{k=1}^K p_k \log_2 p_k$
    - 值域[0,1]，0表示完全纯净
- **分裂质量评估**：
  - **信息增益**：$IG = I(parent) - \sum_{child}\frac{N_{child}}{N_{parent}}I(child)$
    - $I$可以是基尼或熵
  - **信息增益率**：$GainRatio = \frac{IG}{IntrinsicInfo}$（克服多值特征偏好）

### 🌳 建树过程
1. **初始化**：从根节点（全部数据）开始
2. **特征选择**：
   - 对每个特征计算所有可能分割点的信息增益
   - 选择信息增益最大的（特征，分割点）组合
3. **数据划分**：
   - 根据分割点将数据分为左右子集
4. **递归构建**：
   - 对每个子节点重复步骤2-3
5. **生成叶节点**：
   - 当满足停止条件时，叶节点的预测值为：
     - **多数类别**（频率最高的类）
     - 类概率分布（可用于概率预测）

## 📈 回归树（用于连续目标变量）

### 🔎 关键概念
- **目标变量**：连续数值（如房价、温度、销售量）
- **节点纯度衡量**：
  - **平方误差和（SSE）**：$SSE(t) = \sum_{i \in t}(y_i - \bar{y}_t)^2$
    - $y_i$=样本i的目标值
    - $\bar{y}_t$=节点t内所有样本目标值的均值
- **分裂质量评估**：
  - 寻找能使分裂后**SSE总和最小化**的特征和分割点
  - $SSE_{split} = SSE_L + SSE_R$
    - $L/R$为左/右子节点

### 🌳 建树过程
1. **初始化**：从根节点（全部数据）开始
2. **特征选择**：
   - 对每个特征计算所有可能分割点的SSE
   - 遍历每个特征值的中点作为候选分割点
   - 选择使$SSE_{split}$最小的（特征，分割点）组合
3. **数据划分**：
   - 根据分割点将数据分为左右子集（$\leq$和$>$）
4. **递归构建**：
   - 对每个子节点重复步骤2-3
5. **生成叶节点**：
   - 当满足停止条件时，叶节点的预测值为：
     - **均值**：该节点内所有样本目标值的算术平均
     $$ \hat{y} = \frac{1}{|t|}\sum_{i \in t} y_i $$

## 🧪 实例对比

### 分类树示例（是否购买）
| 年龄 | 收入 | 学生 | 购买 |
| ---- | ---- | ---- | ---- |
| 青年 | 高   | 否   | 否   |
| 青年 | 高   | 是   | 是   |
| 中年 | 高   | 否   | 是   |

**决策规则**：  
if 学生?  
├── 是 → 购买  
└── 否 → if 年龄=中年?  
&emsp;&emsp;├── 是 → 购买  
&emsp;&emsp;└── 否 → 不购买  

### 回归树示例（房价预测）
| 面积(m²) | 卧室数 | 房龄 | 房价(万) |
| -------- | ------ | ---- | -------- |
| 80       | 1      | 5    | 300      |
| 100      | 2      | 10   | 350      |
| 120      | 2      | 15   | 380      |

**决策规则**：  
if 面积≤90m² → 预测320万  
if 90<面积≤110m² → 预测345万  
if 面积>110m²:  
&emsp;├── if 房龄≤12年 → 预测385万  
&emsp;└── if 房龄>12年 → 预测350万  

## 🔁 工作流程对比
| 步骤              | 分类树                                       | 回归树                                     |
| ----------------- | -------------------------------------------- | ------------------------------------------ |
| **1. 节点纯度**   | 基尼/熵（类别分布）                          | SSE（目标值方差）                          |
| **2. 分裂目标**   | 最大化纯度提升<br>（信息增益）               | 最小化子节点SSE总和                        |
| **3. 分割点选择** | 类别划分（离散特征）<br>阈值划分（连续特征） | 只考虑连续特征的阈值划分<br>（相邻值中点） |
| **4. 叶节点预测** | 多数类别或概率分布                           | 样本均值（算术平均）                       |
| **5. 停止条件**   | 节点纯净/样本过少/树过深                     | 方差不再显著降低<br>/样本过少/树过深       |

## ⚠️ 注意事项（两者适用）
1. **过拟合风险**：
   - 树过深时会完美拟合训练数据但泛化差
   - 解决方法：剪枝、设置树深度上限
   
2. **特征类型处理**：
   - 数值特征：最优分割点选择
   - 类别特征：one-hot编码或直接分组

3. **树集成**：
   - 单棵树不稳定 → 通过集成提升性能
   - 分类：随机森林（多数投票）
   - 回归：梯度提升树（加权求和）

4. **优点**：
   - 可解释性强（白盒模型）
   - 需要较少的数据预处理（自动处理缺失值）
   - 能处理数值和类别特征

5. **缺点**：
   - 高方差（对训练数据微小变化敏感）
   - 可能创建复杂的分支结构
   - 外推能力差（回归树预测值是范围均值）
